# Система управления хостелами (Учебный проект)

В этом репозитории собраны артефакты учебного проекта по системному анализу:
- Техническое задание (ТЗ)
- Диаграммы BPMN (AS IS и TO BE)
- Диаграммы прецедентов (Use Case)
- Диаграмма классов
- Sequence-диаграммы

Инструменты: Draw.io, BPMN 2.0, UML.
